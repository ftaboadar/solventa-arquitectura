# 3. Plan de trabajo y tablero (10 pts)

Tablero de seguimiento para cerrar esta entrega, derivado directamente de los checklists dejados en cada sección pendiente de [`01-hoja-de-trabajo/`](../01-hoja-de-trabajo/), [`02-estrategia-pruebas/`](../02-estrategia-pruebas/) y [`04-video-evidencias/`](../04-video-evidencias/).

Ver [`tablero.md`](tablero.md) para el tablero Kanban.

## Cómo mantenerlo actualizado

1. Cada vez que se complete un punto del checklist de una sección, mover la tarjeta correspondiente en `tablero.md` a la columna siguiente.
2. Si aparece una tarea nueva no prevista, agregarla en **Backlog** con su sección de destino entre corchetes.
3. Antes de grabar el video de evidencias (ítem 4), todas las tarjetas deberían estar en **Hecho**.
